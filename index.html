Como baixar como app no celular

Este arquivo já está pronto como PWA. Para aparecer o botão de instalar, normalmente precisa abrir por um link HTTPS, como Vercel, GitHub Pages ou Netlify.

  1. Extraia o arquivo ZIP.
  2. Suba a pasta em um serviço como Vercel, GitHub Pages ou Netlify.
  3. Abra o link no Chrome/Edge do celular.
  4. Toque em Instalar app ou no menu do navegador e escolha Adicionar à tela inicial.

Abrindo direto o arquivo index.html, o app funciona para preencher e consultar, mas a instalação offline pode não aparecer por limitação do navegador em arquivos locais.
