APP COPA DO MUNDO 2026

Como usar:
1. Abra o arquivo index.html no navegador para usar localmente.
2. Para instalar como aplicativo no celular, suba esta pasta no Vercel, GitHub Pages ou Netlify.
3. Abra o link HTTPS no Chrome/Edge do celular e toque em "Instalar app" ou "Adicionar à tela inicial".

Observação:
- Os resultados digitados são salvos no navegador do aparelho pelo localStorage.
- Use o botão "Exportar resultados" para fazer backup.
- Use o botão "Importar" para restaurar os resultados em outro aparelho.
