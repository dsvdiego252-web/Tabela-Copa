APP COPA DO MUNDO 2026 - VERSÃO PWA ATUALIZADA

Atualizações desta versão:
- Aba Início mais limpa, sem cartões de estatísticas.
- Nova aba Calendário com junho e julho de 2026.
- Cada dia mostra quantos jogos tem.
- Ao tocar em um dia, aparecem os jogos e horários daquele dia.
- Estatísticas ficaram concentradas somente na aba Estatísticas.

Como atualizar no GitHub/Vercel:
1. Extraia este ZIP.
2. No repositório do GitHub, envie/substitua os arquivos da versão anterior.
3. Faça Commit changes.
4. A Vercel deve atualizar automaticamente o app.
5. No celular, se aparecer a versão antiga, feche e abra o app novamente. Se precisar, limpe o cache do navegador/app.

Observação:
- Os resultados digitados são salvos no navegador do aparelho pelo localStorage.
- Use Exportar resultados antes de atualizar se quiser ter backup.
